# Wireless mode Q channel

<!-- cosem-attributes: 4,4 -->

Configures the device and group addressing used by a wireless mode Q communication channel.

## When to use it

For example, verify an assigned device address and its group address when individual requests work but group requests do not.

## Attributes

### 1. Logical name

Identifies this object instance by its six-part OBIS code. Use it to distinguish this object from other objects of the same class.

### 2. Address State

Reports whether the device has been assigned an address since power up.

### 3. Device Address

Contains the current network address assigned to this device.

### 4. Address Mask

Defines the group address to which the device responds when short form addressing is used.
