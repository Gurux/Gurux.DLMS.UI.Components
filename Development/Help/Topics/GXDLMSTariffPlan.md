# Tariff plan

<!-- cosem-attributes: 5 -->

A tariff plan holds a tariff-switching program with its activation settings. The plan describes the periods and day rules used by the supported device tariff scheme.

## When to use it

Use it to inspect or prepare a tariff program on a device that provides this tariff-plan object.

## Attributes

### 1. Logical name

Identifies this object instance using its six-part OBIS code. Use it to distinguish this object from other instances of the same class.

### 2. Calendar name

Names the tariff calendar or program.

### 3. Enabled

Shows whether the tariff plan is enabled.

### 4. Plan

Contains the default tariff band, winter and summer season settings, weekly activation rules and special days. Each season provides separate intervals for working days, Saturdays and holidays.

### 5. Activation time

Sets the date and time at which the tariff plan is activated.
