# PRIME application identification

<!-- cosem-attributes: 4 -->

Identifies the vendor, product and firmware of a PRIME power line communication implementation.

## When to use it

For example, record the firmware revision before checking whether a group of meters needs a modem update.

## Attributes

### 1. Logical name

Identifies this object instance by its six-part OBIS code. Use it to distinguish this object from other objects of the same class.

### 2. FirmwareVersion

Contains the firmware version of the PRIME implementation.

### 3. VendorId

Identifies the vendor of the PRIME implementation.

### 4. ProductId

Identifies the product within that vendor's product range.
