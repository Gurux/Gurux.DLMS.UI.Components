# M-Bus slave port setup

<!-- cosem-attributes: 5 -->

Configures the speed and address of a device responding as an M-Bus slave.

## When to use it

For example, set a meter address so an M-Bus master can select it individually.

## Attributes

### 1. Logical name

Identifies this object instance by its six-part OBIS code. Use it to distinguish this object from other objects of the same class.

### 2. Default Baud Rate

Selects the baud rate used when the port starts or returns to its default state.

### 3. Available Baud rate

Shows the communication speed available for operation on the port.

### 4. Address State

Reports whether an address has been assigned to the device since power up.

### 5. Bus Address

Contains the bus address used by the master to select this slave.
