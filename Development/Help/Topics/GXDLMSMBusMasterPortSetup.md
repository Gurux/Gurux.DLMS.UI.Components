# M-Bus master port setup

<!-- cosem-attributes: 2 -->

Sets the communication speed of a wired M-Bus port acting as the master.

## When to use it

For example, select the speed required by the heat meters connected to a gateway.

## Attributes

### 1. Logical name

Identifies this object instance by its six-part OBIS code. Use it to distinguish this object from other objects of the same class.

### 2. Comm Speed

Selects the baud rate used by the master port to communicate with attached M-Bus devices.
