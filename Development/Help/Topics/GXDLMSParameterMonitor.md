# Parameter monitor

<!-- cosem-attributes: 4 -->

A parameter monitor records a change to one of a configured set of attributes. It provides the changed parameter and the time of that change.

## When to use it

Use it to identify the latest change to an important meter configuration setting.

## Attributes

### 1. Logical name

Identifies this object instance using its six-part OBIS code. Use it to distinguish this object from other instances of the same class.

### 2. Changed parameter

Identifies the most recently changed object and attribute, together with its recorded value.

### 3. Capture time

Records when the monitored parameter change occurred.

### 4. Parameters

Lists the objects and attributes whose changes are monitored.
