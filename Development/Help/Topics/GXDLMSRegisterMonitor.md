# Register monitor

<!-- cosem-attributes: 4 -->

A register monitor compares a selected measurement with one or more thresholds. It associates upward and downward crossings with script actions.

## When to use it

Use it to trigger an alarm when a voltage crosses an upper or lower boundary.

## Attributes

### 1. Logical name

Identifies this object instance using its six-part OBIS code. Use it to distinguish this object from other instances of the same class.

### 2. Thresholds

Lists the threshold values against which the measurement is compared.

### 3. Monitored value

Identifies the object and attribute whose value is monitored.

### 4. Actions

Defines the upward-crossing and downward-crossing script actions for each threshold.
