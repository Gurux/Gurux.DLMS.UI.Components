# Function control

<!-- cosem-attributes: 3 -->

Function control groups device features into named functional blocks that can be enabled or disabled together. A block can refer to several objects.

## When to use it

Use it to manage whether a named metering or communication function is active.

## Attributes

### 1. Logical name

Identifies this object instance using its six-part OBIS code. Use it to distinguish this object from other instances of the same class.

### 2. Activation status

Lists each functional block and whether it is enabled.

### 3. Function list

Defines the named blocks and the objects participating in each block.
