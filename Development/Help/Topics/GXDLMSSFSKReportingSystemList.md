# S-FSK reporting system list

<!-- cosem-attributes: 2 -->

Lists S-FSK systems that have reported their presence and are still waiting to be registered.

## When to use it

For example, inspect the list to find newly discovered meters waiting for registration.

## Attributes

### 1. Logical name

Identifies this object instance by its six-part OBIS code. Use it to distinguish this object from other objects of the same class.

### 2. ReportingSystemList

Contains the system titles of devices that have sent discovery reports but have not yet been registered. New reports appear first, and registration removes the corresponding device from the list.
