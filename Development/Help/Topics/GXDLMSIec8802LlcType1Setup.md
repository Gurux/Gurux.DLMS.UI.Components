# LLC type 1 setup

<!-- cosem-attributes: 2 -->

Configures the packet size for an unacknowledged, connectionless logical link service.

## When to use it

For example, set a payload limit that the underlying network can carry without exceeding its frame size.

## Attributes

### 1. Logical name

Identifies this object instance by its six-part OBIS code. Use it to distinguish this object from other objects of the same class.

### 2. MaximumOctetsUiPdu

Sets the largest information field, in bytes, allowed in an unnumbered information packet.
