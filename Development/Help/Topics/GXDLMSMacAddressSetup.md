# MAC address setup

<!-- cosem-attributes: 2 -->

This object holds the hardware address used by a network interface. The MAC address identifies the interface on its local link.

## When to use it

Use it to identify a meter on an Ethernet network or match the meter to a network inventory entry.

## Attributes

### 1. Logical name

The OBIS code that identifies this object instance in the meter. Use it to distinguish this instance from other objects of the same class.

### 2. MAC address

Holds the interface's link layer address, commonly shown as six hexadecimal byte pairs for Ethernet.
