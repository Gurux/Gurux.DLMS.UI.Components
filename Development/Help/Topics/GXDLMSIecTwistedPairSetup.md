# Twisted pair setup

<!-- cosem-attributes: 5 -->

This object configures communication over a twisted pair line with carrier signalling. It defines how the meter participates in the network and which addressing information it accepts.

## When to use it

Use it when commissioning meters on a shared twisted pair communication channel.

## Attributes

### 1. Logical name

The OBIS code that identifies this object instance in the meter. Use it to distinguish this instance from other objects of the same class.

### 2. Mode

Selects whether the interface is inactive, always active or uses a manufacturer-specific operating mode.

### 3. Speed

Sets the communication rate supported by the port.

### 4. Primary addresses

Lists the primary station addresses assigned to the device's logical devices.

### 5. TABi values

Lists the TAB(i) response values used when stations are discovered or called without their normal address.
