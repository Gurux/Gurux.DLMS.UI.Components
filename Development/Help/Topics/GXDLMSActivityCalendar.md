# Activity calendar

<!-- cosem-attributes: 10 -->

An activity calendar chooses daily actions through season, week and day profiles. Separate active and passive calendars allow a new timetable to be prepared before it takes effect.

## When to use it

Use it to switch between daytime and night-time tariffs, with different schedules for summer, winter and weekends.

## Attributes

### 1. Logical name

Identifies this object instance using its six-part OBIS code. Use it to distinguish this object from other instances of the same class.

### 2. Active calendar name

Names the calendar currently in operation.

### 3. Active season profile

Defines when each active season starts and which week profile it uses.

### 4. Active week profile table

Maps weekdays to day profiles for the active calendar.

### 5. Active day profile table

Defines the timed script actions in each active day profile.

### 6. Passive calendar name

Names the calendar being prepared for later use.

### 7. Passive season profile

Defines the seasons and their week profiles in the passive calendar.

### 8. Passive week profile table

Maps weekdays to day profiles in the passive calendar.

### 9. Passive day profile table

Defines the timed script actions in the passive day profiles.

### 10. Time

Sets the date and time for activating the passive calendar.
