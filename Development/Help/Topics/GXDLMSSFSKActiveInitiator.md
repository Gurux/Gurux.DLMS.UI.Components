# S-FSK active initiator

<!-- cosem-attributes: 2 -->

Identifies the initiator currently responsible for an S-FSK server on a power line network.

## When to use it

For example, verify that a meter is associated with the expected concentrator after registration.

## Attributes

### 1. Logical name

Identifies this object instance by its six-part OBIS code. Use it to distinguish this object from other objects of the same class.

### 2. Active Initiator

Contains the active initiator's MAC address, service access point selector and system title. These values identify the initiator at both link and application level.
