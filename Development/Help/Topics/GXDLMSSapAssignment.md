# SAP assignment

<!-- cosem-attributes: 2 -->

SAP assignment maps server service access points to logical device names. This helps a client identify the logical devices available through a physical device.

## When to use it

Use it to discover which server address belongs to a particular logical device.

## Attributes

### 1. Logical name

Identifies this object instance using its six-part OBIS code. Use it to distinguish this object from other instances of the same class.

### 2. Sap assignment list

Lists each assigned service access point identifier and its logical device name.
