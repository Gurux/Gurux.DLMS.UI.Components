# Special days table

<!-- cosem-attributes: 2 -->

A special days table assigns day identifiers to calendar dates. Calendar and schedule objects can use these identifiers to apply exceptions to the normal weekday program.

## When to use it

Use it to apply a holiday tariff on a public holiday that falls on a working day.

## Attributes

### 1. Logical name

Identifies this object instance using its six-part OBIS code. Use it to distinguish this object from other instances of the same class.

### 2. Entries

Lists the indexed special dates and their day identifiers. The day identifier selects the applicable special-day behavior in the associated scheduling objects.
