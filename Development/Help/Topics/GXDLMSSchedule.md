# Schedule

<!-- cosem-attributes: 2 -->

A schedule contains individual entries that run scripts at specified times under weekday, date-range and special-day conditions. Each entry can be enabled independently.

## When to use it

Use it to run a control script on selected weekdays during a defined part of the year.

## Attributes

### 1. Logical name

Identifies this object instance using its six-part OBIS code. Use it to distinguish this object from other instances of the same class.

### 2. Entries

Contains the schedule entries, including their identifiers, enable flags, script references, switching times, validity windows and day or date conditions.
