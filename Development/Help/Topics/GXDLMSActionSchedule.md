# Action schedule

<!-- cosem-attributes: 4 -->

An action schedule runs a selected script at configured dates and times. It is useful for timed operations that do not need a full tariff calendar.

## When to use it

Use it to run a billing reset script at midnight on a chosen date.

## Attributes

### 1. Logical name

Identifies this object instance using its six-part OBIS code. Use it to distinguish this object from other instances of the same class.

### 2. Executed script logical name

Identifies the Script table object and the script selector to execute.

### 3. Type

Defines the scheduling pattern and which date or time fields can vary.

### 4. Execution time

Lists the dates and times at which the selected script should run.
