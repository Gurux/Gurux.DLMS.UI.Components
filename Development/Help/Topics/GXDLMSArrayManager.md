# Array manager

<!-- cosem-attributes: 2 -->

An array manager provides a common way to access and maintain arrays stored in other objects. Each managed array is assigned a small identifier.

## When to use it

Use it to retrieve or update selected entries in a large configuration table.

## Attributes

### 1. Logical name

Identifies this object instance using its six-part OBIS code. Use it to distinguish this object from other instances of the same class.

### 2. Objects

Maps array identifiers to the objects and attributes containing the managed arrays.
